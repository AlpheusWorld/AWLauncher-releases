# Проверка обновлений

AWLauncher загружает описание релиза и его отдельную подпись через HTTPS. Подпись Ed25519 проверяется открытым ключом, встроенным в лаунчер. Подменить ключ файлом в публичном репозитории нельзя: он не загружается оттуда как новый источник доверия.

Подпись связывает номер версии, адрес установщика, его размер и SHA-256. Перед запуском установщика проверяются загруженные байты. Отсутствующая или неверная подпись, изменённое описание, неверный размер и несовпадение SHA-256 блокируют установку.

Закрытый ключ хранится отдельно от исходников и дистрибутивов. На машине выпуска он защищён Windows DPAPI; для сборок CI используется секрет GitHub Actions. Открытый ключ опубликован в [assets/update-public-key.txt](assets/update-public-key.txt) для независимой проверки.

Если настроен Authenticode-сертификат, проверка его действительности и отпечатка выполняется дополнительно. Текущий первый публичный выпуск использует подпись описания обновления; это не является доверенной подписью издателя Windows и не создаёт репутацию SmartScreen.

## Сообщить об уязвимости

Отправь описание на **contact@awlauncher.ru**. Для обычных ошибок интерфейса используй Issues. Не публикуй токены аккаунтов, пароли и закрытые ключи.
