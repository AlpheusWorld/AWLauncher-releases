# AWLauncher — Tauri

Интерфейс на Tauri 2: шрифт Onest, тёмная, светлая и OLED темы, навигация, библиотека, каталог, вкладки сборки, галерея и модальное окно настроек.

Операции установки, запуска, авторизации, изменения контента и истории выполняет Rust-движок. В WebView не передаются токены аккаунтов. Файлы, настройки, статистика, переводы и каталог используют общие модули Rust из `rust/ui/src`.

Обычная сборка приложения из корня:

```powershell
.\gradlew.bat createDistributable -PnoDeploy --no-daemon
```

Для локальной проверки без оптимизации Rust добавь `-PawNativeDebug=true`. Сборка выпуска по умолчанию использует профиль `release`.

Запуск окна разработки:

```powershell
cargo run --manifest-path rust/tauri/Cargo.toml
```

На Windows требуется WebView2 Runtime. На Linux для сборки нужны `libwebkit2gtk-4.1-dev` и `libgtk-3-dev`, для запуска — соответствующие runtime-пакеты.

Проверки:

```powershell
cargo test --locked -j 1 --manifest-path rust/tauri/Cargo.toml
cd rust/tauri
npm ci
npx playwright install chromium
npm test
```

Playwright используется только для проверок и не входит в приложение. Проверки выполняются последовательно и закрывают браузер после завершения. `AW_TEST_CHROMIUM` позволяет указать установленный Chromium без дополнительного скачивания.

Сборка Gradle использует до двух рабочих процессов и до 1536 МБ Java heap. Локальная конфигурация Cargo ограничивает сборку Tauri двумя процессами. Для запуска Cargo из корня передавай `-j 2`, поскольку Cargo ищет `.cargo/config.toml` относительно текущей папки.

## Ограничения переноса

Раздел «Друзья» содержит экспериментальное подключение к миру по приглашению. Хозяин открывает мир для локальной сети, указывает порт и отправляет код. Гость вводит код и подключается к показанному локальному адресу из Minecraft. Туннель использует прямое TLS-соединение без посредников, требует UPnP и публичный IPv4 у хозяина; VPS и моды не нужны. Приглашение предоставляет доступ к миру, поэтому передавайте его только доверенным людям. Списка друзей и автоматической проверки совместимости сборок пока нет.

Раздел скинов и плащей встроен в Tauri: библиотека, наборы, поиск, импорт PNG, редактирование, перестановка, плащи и применение профиля. WebGL-превью использует буфер глубины GPU для непрозрачных пикселей; точная сортировка сохраняется только для полупрозрачных поверхностей. При вращении изображение обновляется с частотой экрана, в покое — до 30 кадров в секунду.

Все диалоги сборки встроены в Tauri: общие настройки, память и Java, окно игры, Loader, иконки, группы, экспорт с выбором файлов, дублирование, проверка и применение миграции, восстановление после ошибки миграции, скачивание, переустановка и удаление. Для операций используются существующие менеджеры игрового движка.
