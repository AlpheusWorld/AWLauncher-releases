# AWLauncher — Tauri

Интерфейс на Tauri 2 воспроизводит Kotlin 1.0.49: шрифт Onest, тёмная, светлая и OLED темы, навигация, библиотека, каталог, вкладки сборки, галерея и модальное окно настроек.

Операции установки, запуска, авторизации, изменения контента и истории выполняет существующий JVM-движок через `--native-task`. В WebView не передаются токены аккаунтов. Файлы, настройки, статистика, переводы и каталог используют общие модули Rust из `rust/ui/src`.

Обычная сборка приложения из корня:

```powershell
.\gradlew.bat createDistributable -PnoDeploy --no-daemon
```

Для локальной проверки без оптимизации Rust добавь `-PawNativeDebug=true`. Сборка выпуска по умолчанию использует профиль `release`.

Для отдельного окна разработки нужен собранный JVM-движок той же ревизии:

```powershell
cargo run --manifest-path rust/tauri/Cargo.toml -- --backend "C:/папка-приложения/AWLauncher.exe"
```

На Windows требуется WebView2 Runtime. На Linux для сборки нужны `libwebkit2gtk-4.1-dev` и `libgtk-3-dev`, для запуска — соответствующие runtime-пакеты.

Проверки:

```powershell
cargo test --locked -j 1 --manifest-path rust/tauri/Cargo.toml
cd rust/tauri
npm ci
npx playwright install chromium
npm test
```

Playwright используется только для проверок и не входит в приложение. Проверки выполняются последовательно и закрывают браузер после завершения. `AW_TEST_CHROMIUM` позволяет указать установленный Chromium без дополнительного скачивания.

Сборка Gradle использует до двух рабочих процессов и до 1536 МБ Java heap. Локальная конфигурация Cargo ограничивает сборку Tauri двумя процессами. Для запуска Cargo из корня передавай `-j 2`, поскольку Cargo ищет `.cargo/config.toml` относительно текущей папки.

## Ограничения переноса

Раздел друзей остаётся отключённым, как в egui 1.0.50. Настройки Discord сохраняются для игрового движка; отдельное постоянное соединение с Discord из окна Tauri пока отсутствует.

Скины и расширенные операции сборки открывают исходные Kotlin-экраны в отдельном окне. Основное окно Tauri возвращается после закрытия редактора. Таким образом сохраняются библиотека скинов, наборы, плащи, 3D-превью, миграция сборок и все существующие проверки изменения файлов. При невозможности запуска Tauri основное приложение автоматически использует сохранённый Compose-интерфейс.
