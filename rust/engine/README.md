# Нативные игровые сервисы AWLauncher

Tauri использует Rust для игровых операций и аккаунтов на Windows и Linux.

## Реализовано

- Метаданные и наследование версий, SHA-1/размер, клиентские JAR, Maven-библиотеки, natives, виртуальные ресурсы старых версий. Клиентский JAR именуется по профилю загрузчика — это нужно для `ignoreList` NeoForge.
- Java: манифесты Mojang, установка, проверка файла release, пользовательский путь, поиск локальной Java нужной major-версии.
- Vanilla, Fabric, Quilt, Forge/NeoForge через официальные Java-установщики. Legacy Forge 1.7.10 извлекает versionInfo и встроенную Maven-библиотеку без запуска установщика.
- Подготовка аргументов JVM и игры, память, окно, fullscreen, журнал и PID игры, проверка конфликтов Fabric-модов, отключение старого управляемого awassistant по хешу.
- Параллельная загрузка ресурсов с настройкой downloadConcurrency, повторные попытки, HTTPS-перенаправления только для публичных файлов. Авторизационные запросы не следуют перенаправлениям.
- Переустановка обычных сборок: проверка процессов Minecraft, резервирование версий/natives и восстановление при ошибке или отмене. Миры и пользовательский контент не удаляются.
- Аккаунты: offline UUID, добавление, удаление, выбор; Microsoft Live device-code + Xbox proof-of-possession/SISU без собственного Client ID; обновление существующих aw-ms-device сессий.
- Настроенный Azure Client ID: браузерный PKCE/loopback-вход с проверкой state; OAuth refresh. Совместимое DPAPI-хранилище на Windows и AES-GCM/Secret Service на Linux. Секреты не передаются WebView.
- Скины и плащи: нативный выбор PNG, валидация размеров, библиотека, пресеты, текстуры, редактирование порядка, загрузка/сброс скина и смена доступного плаща.
- Списки Minecraft и загрузчиков, доступные версии для смены версии сборки.

## Граница переноса

На Windows основной EXE запускает Tauri напрямую. Rust загружает состояние, работает с каталогами Modrinth и CurseForge, импортирует модпаки, управляет сборками и снимками, проверяет подписи обновлений. Minecraft и официальные установщики современных Forge и NeoForge требуют Java. Windows-обновлятор использует существующее окно установки на C#.

Полный лицензионный вход, обновление пользовательского refresh-токена и изменение публичного скина/плаща требуют ручной проверки с настоящим аккаунтом. Они не выполнялись на аккаунтах пользователя. Сервер Xbox проверен отдельным запросом авторизации устройства без пользовательской сессии.

Linux Secret Service, Unix runtime со ссылками и нативные файловые диалоги на Linux требуют отдельной проверки. Перед запуском Rust удаляет из servers.dat старую запись VirtusMine, сохраняя остальные записи. Импорт установленных профилей читает метаданные лаунчеров и базы Modrinth App в режиме чтения.

## Проверки

```powershell
cargo test --locked --manifest-path rust/engine/Cargo.toml
$env:AW_ENGINE_TEST_JDK = 'C:/path/to/jdk'
cargo test --locked --manifest-path rust/engine/Cargo.toml -- --include-ignored
cargo check --locked --manifest-path rust/tauri/Cargo.toml
```

Включаемые отдельно тесты запускают изолированное Java-приложение и проверяют подпись устройства на сервере Xbox. Они не изменяют .aw пользователя.

`examples/smoke.rs` запускается вручную с абсолютной тестовой папкой, имя которой начинается с aw-smoke. В ней проверены Minecraft 26.3 Vanilla/Fabric 0.20.1, Minecraft 1.21.1 Quilt/Forge/NeoForge и Legacy Forge 1.7.10 с автоматически установленной Java 8. Журналы подтверждают загрузку рендера/ресурсов; у Legacy Forge также подтверждена загрузка тестового мира. Это проверка указанных сочетаний, а не всех выпусков игры.
