# Экспериментальная проверка файлов на Rust

Библиотека `aw-hash` вычисляет SHA-1 для файлов через общий `sha1Of(path)` и SHA-256 для проверки ранее встроенного мода. Это затрагивает проверку кэша, модов, сборок и других файлов, использующих общий метод. Формат `verify.index`, проверка размера и логика хранения кэша остаются прежними. Потоковые хеши, проверка обновлений и сетевые операции пока выполняются на JVM. Если библиотека не включена или не смогла прочитать файл, используется реализация JVM.

Для экспериментальной сборки Windows или Linux x64 нужны JDK 21 и установленный Rust с Cargo:

```powershell
.\gradlew.bat test -PawRustHash=true -PnoDeploy
.\gradlew.bat createDistributable -PawRustHash=true -PnoDeploy
```

На Linux используй `./gradlew` вместо `gradlew.bat`. Без `-PawRustHash=true` Rust не требуется и сборка использует реализацию JVM. Для воспроизводимости зависимости закреплены в `Cargo.lock`. Библиотека не загружается из сети во время работы лаунчера.

Это первый эксперимент: перенос не заменяет интерфейс или Java и сам по себе не обещает ускорения. Перед включением в релизы нужно проверить производительность и пакеты Windows и Linux, а также учесть лицензии Rust-зависимостей.
