# Экспериментальный интерфейс AWLauncher на Rust

Это начало переноса: главная страница и библиотека читают локальные сборки и установленные модпаки из данных AWLauncher. Страница сборки показывает файлы модов, шейдеров, ресурспаков и датапаков по мирам, включая отключённые, и позволяет искать их. Код чтения каталогов находится на Rust. На странице контента работают переключатели ресурспаков и шейдеров: они сохраняют изменения в `options.txt` и `config/iris.properties` соответственно. Состояние модов пока доступно только для чтения. Действия запуска передаются установленному Kotlin-лаунчеру через его существующие аргументы `--play`, `--loader`, `--build` и `--pack`. Также доступны просмотр уведомлений, галерея скриншотов, файлы и миры сборки, журнал и базовая активность. Добавлен экспериментальный поиск Modrinth и CurseForge; установка проектов и их страницы внутри лаунчера ещё не перенесены. Остальные экраны пока доступны только в прежнем лаунчере.

Для сборки нужен Rust и Cargo:

```powershell
cargo test --locked --manifest-path rust/ui/Cargo.toml
cargo build --locked --manifest-path rust/ui/Cargo.toml
.\rust\ui\target\debug\awlauncher-ui.exe --backend "C:\путь\к\AWLauncher.exe"
```

На Linux используй `rust/ui/target/debug/awlauncher-ui` и путь к исполняемому файлу установленного лаунчера. Вместо `--backend` можно задать переменную окружения `AW_LAUNCHER_BACKEND`. Если рядом находится `AWLauncher.exe` (или `AWLauncher` на Linux), он подхватится автоматически.

Пока это тестовая версия: дизайн ещё не совпадает с текущим интерфейсом 1:1, а переключение модов с проверкой зависимостей, остальные экраны, полная локализация, установка проектов, установщик и обновление не перенесены. Запуск Minecraft и взаимодействие с действующим лаунчером ещё требуют ручной проверки. Не заменяй ею установленный AWLauncher.

## Визуальный перенос

`src/visual.rs` содержит воспроизведение главной страницы, верхней панели, строк библиотеки, заголовка сборки, нижней панели аккаунта, страницы аккаунтов и оболочки настроек по Compose-исходникам. Используются оригинальные шрифты Onest, логотип и изображения сборок. Полного соответствия всех экранов пока нет: настройки заполнены частично, отсутствуют полноценные друзья, загрузки, редактор скина и ряд диалогов. Авторизация на странице аккаунтов отключена до подключения движка. Смена темы в тестовом окне действует только в текущем сеансе.

## Настройки

Общие параметры, память, аргументы JVM, список версий, тема, язык, потоки загрузки и флаги Discord сохраняются в совместимый `launcher.json`. Изменяется только выбранное поле; неизвестные поля сохраняются. Запись отклоняется при занятой блокировке установленного лаунчера или повреждённом JSON. Смена темы применяется сразу, настройки игрового движка — при его следующем запуске. Список содержит 50 языков с оригинальными флагами и шрифтами; полный перевод Rust-интерфейса, Discord IPC и автообновление ещё не перенесены.

## Статистика

Экран активности воспроизводит карточки показателей, недельный график, календарь, любимые версии и серверы и последние сессии. Поддерживаются подсказки и переключение недель, общая статистика и вкладка статистики выбранной сборки. Расчёт использует сохранённую историю, обычные и GZIP-журналы и импортированное время без двойного учёта. Новые данные сохраняются отдельно от исходной истории.
