# Интерфейс AWLauncher на Rust

В версии 1.0.50 Rust-интерфейс входит в обычное приложение AWLauncher. Он читает те же сборки, настройки и историю из `.aw`. Проверенный JVM-движок выполняет запуск Minecraft, авторизацию, установку и проверку файлов, разрешение зависимостей модов и восстановление снимков.

В интерфейс перенесены главная страница, библиотека, настройки, статистика, аккаунты, уведомления, скриншоты, каталоги Modrinth и CurseForge, страницы проектов и очередь загрузок. Страница сборки включает контент с переключателями и массовыми действиями, файлы, миры, журнал, статистику и историю. Описания проектов используют тот же CommonMark-парсер и обработку SVG, что и Compose-версия. Переводы берутся из исходных словарей лаунчера. Раздел «Друзья» отключён.

## Сборка

Нужны JDK 21, стабильный Rust, Python 3 и зависимости рабочего стола для Linux. Сборка приложения из корня репозитория:

```powershell
.\gradlew.bat createDistributable -PnoDeploy
```

В Linux используется `./gradlew`. Gradle собирает Rust-бинарник, JVM-движок и комплектное окружение Java в одну папку приложения. Для разработки отдельного окна:

```powershell
cargo run --manifest-path rust/ui/Cargo.toml -- --backend "ПУТЬ-К-ПАПКЕ-ПРИЛОЖЕНИЯ/AWLauncher.exe"
```

Указанная папка должна быть собрана через `createDistributable`: адаптер использует комплектный Java runtime и протокол `--native-task`. Для запуска сохранённого Compose-интерфейса передай `--compose-ui` основному исполняемому файлу.

## Проверки

```powershell
cargo test --locked --manifest-path rust/ui/Cargo.toml
.\gradlew.bat test nativeBackendSmoke -PnoDeploy
python tools/tests/native_backend_smoke.py build/compose/binaries/main/app/AWLauncher
```

Последняя команда проверяет изменения контента и историю в отдельном временном профиле. Явно включаемые сетевые smoke-тесты помечены `ignored` и запускаются отдельно.
