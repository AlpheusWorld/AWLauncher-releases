# Сайт AWLauncher

Промо-страница AWLauncher с текстом и скачиванием слева, превью интерфейса справа, описанием возможностей и инструкциями по установке. Палитра взята из текущей темы лаунчера: изумруд `#54C68A`, графит `#101213`, шрифт Onest. Карточки и пиксельные иконки продолжают оформление приложения.

В качестве референсов изучены [Modrinth App](https://modrinth.com/app), [Prism Launcher](https://prismlauncher.org/) и [Raycast](https://www.raycast.com/): показ интерфейса рядом с основным действием, короткие описания возможностей и ясная иерархия. Изображения, логотип и шрифты используются свои.

## Что внутри

```
awlauncher-site/
├─ index.html            разметка страницы
├─ styles.css            токены темы, вёрстка, анимации
├─ script.js             темы, языки, меню, мокап лаунчера
├─ README.md             этот файл
└─ assets/
   ├─ fonts/             Onest (Regular, Medium, SemiBold, Bold, Black) + Onest-OFL.txt
   └─ img/               логотипы, icon-32/48/64.png, пейзаж PNG/WebP, иконки сборок
```

Зависимостей и отдельной сборки нет. Шрифты и изображения локальные. Страница открывается двойным щелчком по `index.html`; для проверки автоматического обновления сведений удобнее HTTP-предпросмотр.

## Как посмотреть локально

```powershell
start index.html
```

Если нужен HTTP-сервер (например, для проверки на телефоне в той же сети):

```powershell
python -m http.server 8080
# затем http://localhost:8080
```

## Что умеет страница

- **Переключатель систем в разделе «Установка»** — Windows показывает официальный `AWLauncher-Setup.exe`; MSI также доступен на публичной странице релиза. Linux и macOS показывают отсутствие официальных пакетов, без неподтверждённых инструкций по сборке deb/rpm/dmg. Данные лежат в `SYSTEMS` в `script.js`.
- **Актуальные данные** — при загрузке выполняются два асинхронных запроса: официальный манифест Mojang для релиза, снапшота и числа версий; GitHub API публичного репозитория для версии AWLauncher и размера EXE. Запросы ограничены десятью секундами и не повторяются по таймеру. Если сеть недоступна, сохраняются проверенные значения из разметки и скрипта; переключение языка обновлённые данные не сбрасывает.
- **Объёмный просмотр скина** — воксельная фигура собрана на CSS 3D из шести коробок (голова, корпус, две руки, две ноги), по шесть граней у каждой. Скрипт строит её из массива `VOX_PARTS`. Модель поворачивается только при перетаскивании и переключается между Classic и Slim.
- **Четыре темы** — светлая, тёмная, системная и OLED. Кнопки в разделе «Оформление» переключают тему самой страницы и запоминаются в `localStorage` (`aw-theme`). Выбор темы применяется до первой отрисовки, поэтому вспышки белым при загрузке нет. Логотип меняется на светлую версию автоматически.
- **Два языка** — русский (текст лежит прямо в `index.html`) и английский (словарь `EN` в `script.js`). Переключатель `RU / EN` в верхней панели и в мобильном меню, выбор запоминается в `aw-lang`. Русский текст снимается из разметки при загрузке, поэтому дублировать его в скрипте не нужно. Принудительно открыть страницу на английском можно атрибутом `data-lang="en"` на теге `<html>`.
- **Мобильное меню** — открывается без размывания фона, удерживает клавиатурный фокус внутри и возвращает его на кнопку при закрытии. Закрытие по `Esc`, клику по ссылке и при возврате окна к ширине больше 1120 px.
- **Мокап лаунчера** — статичное демонстрационное окно с библиотекой сборок, журналом проверки файлов и существующими иконками из ресурсов приложения. Кнопка «Играть» внутри превью иллюстративная; скачивание доступно через основные кнопки страницы.
- **Анимации** — блоки плавно появляются при первом попадании в экран, меню открывается с коротким переходом, карточки и кнопки реагируют на наведение, ответы FAQ раскрываются плавно. Появление использует `IntersectionObserver`; после показа блок снимается с наблюдения. Без JavaScript содержимое остаётся видимым.
- **Нагрузка в покое** — нет бесконечных анимаций, повторяющихся таймеров, `blur` и `backdrop-filter`. Анимации появления завершаются за 0,6 секунды. Единственный `requestAnimationFrame` обслуживает события прокрутки и изменения размера окна.
- **Доступность** — ссылка «Перейти к содержимому», семантика `nav`/`main`/`footer`, `aria-expanded` у меню и аккордеона, `role="tablist"` у переключателей, видимый фокус, `prefers-reduced-motion` глушит все анимации.

## Порядок разделов

`hero → возможности → загрузчики → сборки → аккаунты и скин → Discord → темы и локали → установка → частые вопросы → футер`

Кнопки «Скачать» ведут к разделу установки. Отдельный повторный блок загрузки удалён.

## Как поменять содержимое

| Что | Где |
| --- | --- |
| Ссылки на релиз и репозиторий | `index.html`, атрибуты `href` у кнопки в разделе «Установка» и ссылок в футере; данные систем в `script.js` |
| Русский текст | прямо в `index.html`, атрибут `data-i18n="ключ"` |
| Английский текст | объект `EN` в `script.js` — тот же ключ |
| Тексты панели загрузчиков | объект `LOADERS` в `script.js` (по ключам `fabric`, `forge`, `neoforge`, `quilt`) |
| Сведения о Windows, Linux, macOS | объект `SYSTEMS` и функция `unavailableSystem` в `script.js` |
| Фигура персонажа в просмотре скина | массив `VOX_PARTS` в `script.js` (размеры, смещения и цвета частей) |
| Строки статичного журнала в мокапе | массив `LOG_STEPS` в `script.js` |
| Палитра и темы | блок токенов в начале `styles.css`: `:root`, `[data-theme="light"]`, `[data-theme="oled"]`, медиазапрос для системной темы |
| Логотип и иконки | `assets/img/` |

Ключи локализации удобно проверять так: в консоли браузера выполнить `document.querySelectorAll('[data-i18n]').length` и сравнить с числом ключей в `EN`.

## Публикация

Вариант 1 — GitHub Pages из отдельной ветки или папки репозитория: залей содержимое `awlauncher-site` в ветку `gh-pages`, и страница откроется по адресу вида `https://<организация>.github.io/AWLauncher/`.

Вариант 2 — отдельный репозиторий сайта: тот же набор файлов в корне, включи Pages для ветки `main`, папка `/` (root).

Вариант 3 — любой статический хостинг (Netlify, Cloudflare Pages, свой nginx): достаточно выложить папку целиком.

Если сайт кладётся в основной репозиторий лаунчера, лучше в отдельную папку (`site/` или `docs/`), чтобы не мешать Gradle и релизным workflow. После публикации на известном домене можно добавить `canonical` и `og:url`. Старые значения указывали на несуществующую страницу и удалены; Open Graph использует доступное изображение публичного репозитория.

## Замечания по ассетам

- Шрифты Onest распространяются по лицензии SIL OFL; текст лицензии лежит рядом в `assets/fonts/Onest-OFL.txt` и его стоит сохранять при публикации.
- `aw-home-hero.webp` — статичный пейзаж первого экрана, около 217 КиБ вместо 2,1 МБ исходного PNG. Исходник `aw-home-hero.png` сохранён; для Open Graph используется его публичная копия.
- `instance-crystal.png`, `instance-grass.png`, `instance-anvil.png` — копии существующих иконок сборок из `src/main/resources/instance-icons` лаунчера, используемые в превью и разделе сборок.
- Проект не связан с Mojang Studios и Microsoft; эта оговорка уже есть в футере страницы и её лучше не удалять.
