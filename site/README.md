# Сайт AWLauncher

Промо-страница лаунчера AWLauncher: одна прокручиваемая страница с описанием возможностей, каталогов, загрузчиков, тем и порядком установки. Вёрстка и палитра взяты из самого лаунчера — изумруд `#32C879`, графит `#111114`, шрифт Onest.

## Что внутри

```
awlauncher-site/
├─ index.html            разметка страницы
├─ styles.css            токены темы, вёрстка, анимации
├─ script.js             темы, языки, меню, мокап лаунчера
├─ README.md             этот файл
└─ assets/
   ├─ fonts/             Onest (Regular, Medium, SemiBold, Bold, Black) + Onest-OFL.txt
   └─ img/               wordmark.png, aw-mark.png, icon-16…64.png, aw-home-hero.png
```

Зависимостей нет: ни сборки, ни npm, ни CDN. Открывается двойным щелчком по `index.html`.

## Как посмотреть локально

```powershell
start index.html
```

Если нужен HTTP-сервер (например, для проверки на телефоне в той же сети):

```powershell
python -m http.server 8080
# затем http://localhost:8080
```

## Что умеет страница

- **Переключатель систем в разделе «Установка»** — три вкладки: Windows, Linux и macOS. Для Windows показывается подписанный `.msi`, для Linux и macOS — сборка из исходников с готовой командой и кнопкой «Копировать». Данные лежат в объекте `SYSTEMS` в `script.js`: значок, бейдж, имя файла, строки таблицы, команда, текст кнопки, ссылка, примечание и три шага. Добавить систему — значит добавить ещё один ключ и вкладку в разметку.
- **Объёмный просмотр скина** — воксельная фигура собрана на CSS 3D из шести коробок (голова, корпус, две руки, две ноги), по шесть граней у каждой. Скрипт строит её из массива `VOX_PARTS`. Модель вращается сама, поворачивается перетаскиванием мышью и переключается между Classic и Slim. Анимация останавливается, когда секция вне экрана или вкладка браузера неактивна.
- **Четыре темы** — светлая, тёмная, системная и OLED. Кнопки в разделе «Оформление» переключают тему самой страницы и запоминаются в `localStorage` (`aw-theme`). Выбор темы применяется до первой отрисовки, поэтому вспышки белым при загрузке нет. Логотип меняется на светлую версию автоматически.
- **Два языка** — русский (текст лежит прямо в `index.html`) и английский (словарь `EN` в `script.js`). Переключатель `RU / EN` в верхней панели и в мобильном меню, выбор запоминается в `aw-lang`. Русский текст снимается из разметки при загрузке, поэтому дублировать его в скрипте не нужно. Принудительно открыть страницу на английском можно атрибутом `data-lang="en"` на теге `<html>`.
- **Морф-меню** — на узких экранах иконка превращается в крестик, ссылки выезжают по очереди, фон размывается. Закрытие по `Esc`, клику по ссылке и при возврате окна к ширине больше 1120 px.
- **Мокап лаунчера** — окно с журналом проверки файлов и полосой загрузки. Строки идут по кругу, полоса заполняется заново.
- **Живые мелочи** — таймер сессии в карточке Discord, блик под курсором на карточках, магнитные кнопки, бегущие строки загрузчиков и локалей.
- **Доступность** — ссылка «Перейти к содержимому», семантика `nav`/`main`/`footer`, `aria-expanded` у меню и аккордеона, `role="tablist"` у переключателей, видимый фокус, `prefers-reduced-motion` глушит все анимации.

## Порядок разделов

`hero → возможности → загрузчики → сборки → аккаунты и скин → Discord → темы и локали → частые вопросы → установка → скачать → футер`

Установка идёт после вопросов, потому что часть ответов ссылается на команды сборки из исходников.

## Как поменять содержимое

| Что | Где |
| --- | --- |
| Ссылки на релиз и репозиторий | `index.html`, атрибуты `href` у кнопок в разделах «Установка» и «Скачать», а также в футере |
| Русский текст | прямо в `index.html`, атрибут `data-i18n="ключ"` |
| Английский текст | объект `EN` в `script.js` — тот же ключ |
| Тексты панели загрузчиков | объект `LOADERS` в `script.js` (по ключам `fabric`, `forge`, `neoforge`, `quilt`) |
| Тексты и команды для Windows, Linux, macOS | объект `SYSTEMS` в `script.js` (по ключам `windows`, `linux`, `macos`) |
| Фигура персонажа в просмотре скина | массив `VOX_PARTS` в `script.js` (размеры, смещения и цвета частей) |
| Строки журнала в мокапе | массив `LOG_STEPS` в `script.js` |
| Палитра и темы | блок токенов в начале `styles.css`: `:root`, `[data-theme="light"]`, `[data-theme="oled"]`, медиазапрос для системной темы |
| Логотип и иконки | `assets/img/` |

Ключи локализации удобно проверять так: в консоли браузера выполнить `document.querySelectorAll('[data-i18n]').length` и сравнить с числом ключей в `EN`.

## Публикация

Вариант 1 — GitHub Pages из отдельной ветки или папки репозитория: залей содержимое `awlauncher-site` в ветку `gh-pages`, и страница откроется по адресу вида `https://<организация>.github.io/AWLauncher/`.

Вариант 2 — отдельный репозиторий сайта: тот же набор файлов в корне, включи Pages для ветки `main`, папка `/` (root).

Вариант 3 — любой статический хостинг (Netlify, Cloudflare Pages, свой nginx): достаточно выложить папку целиком.

Если сайт кладётся в основной репозиторий лаунчера, лучше в отдельную папку (`site/` или `docs/`), чтобы не мешать Gradle и релизным workflow. Канонический адрес страницы задаётся в `index.html` в теге `<link rel="canonical">` — замени его на свой перед публикацией.

## Замечания по ассетам

- Шрифты Onest распространяются по лицензии SIL OFL; текст лицензии лежит рядом в `assets/fonts/Onest-OFL.txt` и его стоит сохранять при публикации.
- `aw-home-hero.png` — фон баннера сборки в мокапе лаунчера, файл на 2,1 МБ. Если важна скорость загрузки, его стоит пережать в WebP или AVIF.
- Проект не связан с Mojang Studios и Microsoft; эта оговорка уже есть в футере страницы и её лучше не удалять.
