    Установка

    Установи и начни играть

    Готовые установщики выпускаются для Windows 10 и 11, 64-бит. Выбери систему, чтобы посмотреть доступные варианты.

    1. 01

      Скачай EXE и запусти установщик

      Открой AWLauncher-Setup.exe из официального релиза и выбери папку. MSI включён в EXE; отдельно устанавливать Java для лаунчера не нужно.

    2. 02

      Войди в аккаунт

      Открой «Аккаунты» → «Войти через Microsoft» и подтверди вход в браузере. Нужен аккаунт с Minecraft Java Edition. Офлайн-профиль подходит для совместимых серверов.

    3. 03

      Создай сборку

      Выбери версию игры и подходящий загрузчик, добавь моды и нажми «Играть». Java подбирается по выбранной версии Minecraft, а сборки хранятся в .aw/instances.

    Установщик содержит Java для лаунчера. Файлы Minecraft загружаются отдельно. У первого установщика пока нет доверенного Authenticode-сертификата Windows; подпись обновлений Ed25519 проверяется отдельно.

    Что понадобится

    • Windows 10 или 11, 64-бит
    • Для входа через Microsoft — аккаунт с Minecraft Java Edition
    • Интернет для первой загрузки игры, Java и выбранных модов
    • Java для самого лаунчера уже включена в установщик

    Как проверяется релиз

    • Описание обновления подписано Ed25519, лаунчер проверяет подпись до установки
    • Перед обновлением проверяются размер и SHA-256 установщика
    • Релизы доступны всем в публичном репозитории; доверенного сертификата Authenticode у первого установщика пока нет

    Вопросы

    Есть вопросы?

    Для входа через Microsoft нужен аккаунт с Minecraft Java Edition. Офлайн-профиль подходит для серверов, которые поддерживают вход без проверки лицензии: online-mode=false.

    В папку .aw внутри домашней папки пользователя. Сборки лежат в .aw/instances; у каждой свои mods, saves, resourcepacks, shaderpacks и config. Общие библиотеки, файлы игры и Java хранятся отдельно.

    «Новая сборка» → импорт из папки. Укажи профиль, .minecraft или общий каталог instances — AWLauncher определит Prism, MultiMC, Modrinth, CurseForge или ATLauncher и скопирует содержимое. Статистика времени и логи подхватятся, часы не удвоятся.

    Каталог CurseForge работает с официальным API-ключом AlpheusWorld. В собственной сборке его можно задать через AW_CURSEFORGE_API_KEY или .aw/curseforge_api_key.txt. Если ключ не настроен или автор запретил стороннюю загрузку, лаунчер не обходит ограничение; Modrinth продолжает работать.

    В журнал сборки: лаунчер разбирает вывод игры и подсказывает причину. Сначала проверь файлы профиля и объём памяти — это две самые частые причины.

    Лаунчер предложит значение под твою машину. Для крупных сборочных профилей с сотней модов обычно хватает 4–8 ГБ; выставлять всю память компьютера не стоит.

    Клиентский мод для поиска правил сервера внутри Minecraft, открывается по F8. В AWLauncher 1.0.11 он автоматически подключается к Fabric 26.1.2 и 26.3 с Java 25 и Fabric Loader 0.19.3 или новее. Автоустановку можно отключить в «Настройки → Игра → Клиентский мод AWAssistant».
