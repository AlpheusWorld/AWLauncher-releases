# AWLauncher — лаунчер Minecraft для Windows

AWLauncher помогает установить Minecraft Java Edition, подобрать загрузчик и держать игровые сборки отдельно друг от друга.

Исходный код и дистрибутивы AWLauncher доступны по [MIT](LICENSE). Публичный репозиторий с кодом, релизами и обсуждениями: [AlpheusWorld/AWLauncher-releases](https://github.com/AlpheusWorld/AWLauncher-releases). Сторонние библиотеки и ресурсы сохраняют собственные лицензии.

## Интерфейс и активность

В 1.0.8 появился отдельный раздел «Скины»: крупное превью, библиотека PNG, девять стандартных персонажей и редактирование модели рук/плаща. Выбор плитки меняет предпросмотр, а кнопка «Применить» отправляет изменение в Minecraft. Общая «Активность» учитывает все профили AWLauncher и перенесённые сборки; время неперенесённых сборок Modrinth в неё не входит.

## Возможности


- Релизы, снапшоты, alpha и beta версии Minecraft
- Fabric, Forge, NeoForge и Quilt
- Каталоги Modrinth и CurseForge: моды, сборки, ресурспаки и шейдеры
- Именованные профили Minecraft с выбором версии и загрузчика
- Автоматическая установка Java для выбранной версии
- Отдельная папка и настройки для каждой сборки
- Проверка загруженных файлов и понятные подсказки при вылетах
- Светлая, тёмная, системная и OLED тема
- Русский, английский и испанский языки
- Собственная верхняя панель окна и единая навигация
- Выбор объёма памяти вручную и рекомендация для компьютера
- Discord Rich Presence: сборка, версия игры, режим, таймер сессии и кнопка страницы сборки

## Изменение версии сборки

В меню существующей сборки выбери «Изменить версию Minecraft». Проверка по хешам на Modrinth подберёт версии модов для новой версии игры и текущего загрузчика. Для модов без подходящего выпуска можно выбрать, оставить их включёнными или отключить. Сначала загружаются новые файлы, затем обновляется существующий профиль с тем же именем, папкой и историей. Миры и конфиги не копируются и не изменяются. Старые моды и настройки сохраняются в `aw-migration-backups` внутри сборки; при ошибке применения они возвращаются автоматически.

## Очередь загрузок

В разделе «Загрузки» отображаются установки модов, шейдеров, ресурспаков, сборок и файлов Minecraft. Можно добавлять несколько проектов из каталога: они устанавливаются по очереди с сохранением параллельной загрузки файлов внутри задачи. Доступны прогресс, скорость, отмена, выбор следующей задачи и повтор после ошибки. Пауза позволяет текущей задаче завершиться и откладывает следующие. Через меню сборки → «Скачать файлы» можно подготовить Minecraft без запуска игры.


## Активность Discord

В «Настройки → Discord» можно включить активность, показывать только игру, скрыть название сборки или отдельно разрешить показ адреса сервера. Адрес сервера по умолчанию скрыт. Лаунчер подключается к установленному Discord через локальный Windows IPC; вход, бот и токены Discord не требуются. После закрытия игры карточка возвращается к лаунчеру, при отключении функции очищается. Перезапуск Discord обрабатывается автоматически.

Карточка использует логотип AWLauncher и отдельные изображения запуска, меню, одиночной и сетевой игры. Для сборок из Modrinth и CurseForge доступны публичная обложка и кнопка страницы проекта. Локальные изображения не загружаются в Discord. Иконки публичных серверов доступны только при разрешённом показе адреса; локальные адреса не отправляются в сервис иконок. Режим определяется по запуску игры и распознаваемым событиям её журнала, без установки мода.

Публичный Discord Application ID `1555994295134326945` встроен в сборку. Его можно переопределить через `AW_DISCORD_APP_ID`, Gradle `-PawDiscordAppId=…` или локальный `.aw/discord_app_id.txt`. Для другого приложения зарегистрируй изображения с ключами `awlauncher`, `playing`, `singleplayer`, `multiplayer`, `launching`. Команда `gradlew renderScreens -PnoDeploy -Pscreens=discord-assets` экспортирует исходные изображения в `build/preview`; она не запускает лаунчер. В Actions доступна переменная `AW_DISCORD_APP_ID`; при её отсутствии используется встроенный ID. Изменения карточки объединяются и отправляются не чаще раза в пять секунд, отключение активности обходит этот интервал. Проверка подключения выполняется раз в 15 секунд, без таймера на каждый кадр интерфейса.

## Профили сборок

Открой в лаунчере раздел «Сборки» и создай профиль: задай название, версию Minecraft и загрузчик. Каждый профиль хранит в своей папке миры, моды, настройки, ресурспаки и шейдеры. Можно начать с пустого профиля, импортировать `.mrpack` или скопировать папку профиля из Prism, CurseForge и другого лаунчера. Профили можно переключать, переименовывать и удалять независимо друг от друга.

## Анимации и переключение контента

Переключатели плавно меняют состояние за 170 мс; прокрутка не проигрывает анимацию для вновь видимых строк. При отключении мода сохраняются его название, метаданные, выделение и положение в списке. Файловая операция выполняется в фоне, без повторного распознавания всей сборки и сетевой проверки обновлений; при ошибке интерфейс восстанавливает подтверждённое состояние. Переходы страниц и настроек используют лёгкое движение слоёв, наведение и нажатия — короткие согласованные анимации.

## Скриншоты

Раздел «Скриншоты» в боковом меню показывает снимки всех сборок, а одноимённая вкладка внутри сборки — только её изображения. Новые снимки идут первыми; доступны поиск и фильтр по сборке. Нажми на миниатюру, чтобы открыть изображение в лаунчере, и перелистывай кнопками или стрелками клавиатуры. Escape возвращает галерею. Снимки читаются из игровых папок `screenshots`, список обновляется автоматически и кнопкой «Обновить». Файлы не изменяются и не отправляются в интернет.

## Установка

Скачай `AWLauncher-Setup.exe` с [официальной публичной страницы релизов](https://github.com/AlpheusWorld/AWLauncher-releases/releases/latest). Установщик включает необходимые файлы лаунчера; игровые сборки хранятся отдельно.

Нужна Windows 10 или 11, 64-бит. Для лицензии открой «Аккаунты» → «Войти через Microsoft» и подтверди вход в браузере. Офлайн-аккаунты работают только на серверах с `online-mode=false`.

## Microsoft-вход

В локальной сборке без собственного ID приложения доступен вход Microsoft по коду через [MinecraftAuth](https://github.com/RaphiMC/MinecraftAuth) 5.0.2. Используется стандартная конфигурация Minecraft Java Edition из библиотеки; это не регистрация AWLauncher в Microsoft. Пароль вводится только на странице Microsoft. Лаунчер проверяет лицензию и профиль, защищает токены Windows DPAPI и автоматически обновляет сессию. Вход можно отменить в разделе аккаунтов.

При настройке собственного ID применяется PKCE-вход через системный браузер. Для выпуска релизов со своим приложением:

1. Зарегистрируй AWLauncher как публичное desktop-приложение Microsoft Entra для личных Microsoft-аккаунтов и укажи loopback redirect `http://localhost`.
2. Добейся одобрения приложения для Minecraft Services.
3. Добавь `AW_MS_CLIENT_ID` как Actions variable в репозитории. Это публичный идентификатор приложения; client secret лаунчеру не нужен.

Сборка релиза завершится ошибкой, если идентификатор или подпись не настроены. Для локальной разработки можно задать `AW_MS_CLIENT_ID` в окружении либо положить ID в `.aw/client_id.txt`.

## Подписанные релизы и автообновление

Начиная с 1.0.2 лаунчер использует публичный HTTPS-фид `https://github.com/AlpheusWorld/AWLauncher-releases/releases/latest/download/update.json`. Описание подписывается Ed25519; открытый ключ встроен в приложение, подпись загружается с неизменяемого адреса конкретного релиза. Перед установкой проверяются подпись описания, размер и SHA-256 MSI. Проверка выполняется при запуске, раз в шесть часов и вручную в «Настройки → О лаунчере». Загрузка отменяется, установка сохраняет фактическую папку лаунчера и откладывается, пока запущен Minecraft.

Старые сборки 1.0.1 и прежняя 1.6.7 требуют одного ручного перехода на установщик 1.0.3: в них нет нового ключа проверки. Для публичного выпуска используется Eclipse Temurin 21; лицензии входят в образ приложения, а необходимые исходники сторонних компонентов и OpenJDK сопровождают релиз.

Закрытый ключ создан через `tools/create_update_key.ps1` и хранится вне Git в `%USERPROFILE%/.aw-release-signing`, защищённый Windows DPAPI. Его копия передаётся только в секрет `AW_UPDATE_SIGNING_PRIVATE_KEY` GitHub Actions репозитория проекта. Открытый ключ находится в `src/main/resources/update/public-key.txt`. Не создавайте новый ключ поверх существующего: старые клиенты доверяют прежнему.

Для выпуска подготовь `releases/<version>.md`, увеличь номер в Gradle и `ArgumentBuilder`, затем собери пакет, выполни `tools/prepare_release_sources.ps1 -Version <version>` и `tools/publish_release.ps1 -Version <version> -Notes releases/<version>.md`. Для публикации нужны PowerShell 7, JDK 21 и Python 3; путь к Python можно передать через `-PythonExecutable`. Дополнительные Python-пакеты не требуются. Скрипт подписывает описание, проверяет подпись и публикует готовые файлы через черновик релиза в публичном репозитории. Он использует локальные GitHub credentials; токен не сохраняется в файлы. Для автоматической публикации из CI можно отдельно настроить `AW_PUBLIC_RELEASE_TOKEN` — fine-grained token только с Contents: write для публичного репозитория релизов. Без него CI сохраняет проверенный пакет как приватный artifact для последующей публикации владельцем; широкий пользовательский токен в CI не копируется.

Authenticode остаётся дополнительной проверкой, когда настроен сертификат. Текущий выпуск использует подпись описания обновления; это не подпись издателя Windows и не репутация SmartScreen. Для первого установщика Windows может показывать предупреждение.

## Сборка

### Каталог CurseForge

В каталоге выбери Modrinth или CurseForge. CurseForge поддерживает поиск, выбор версии, обязательные зависимости, обновления и импорт сборок `.zip` с `manifest.json`. Существующие профили и сборки Modrinth продолжают работать.

Для CurseForge нужен официальный API-ключ AlpheusWorld. Подай заявку по ссылке в [документации CurseForge](https://docs.curseforge.com/rest-api/#an-introduction-to-curseforge). После получения задай `AW_CURSEFORGE_API_KEY` в окружении перед запуском или положи ключ в `%USERPROFILE%/.aw/curseforge_api_key.txt` и перезапусти лаунчер. Ключ в Git не добавляй. Публичный релизный workflow собирает установщики без встроенного ключа CurseForge; локальная настройка хранится отдельно от папки приложения и сохраняется после обновления.

Ключ в desktop-приложении технически можно извлечь из дистрибутива; используй только ключ, одобренный CurseForge для распространяемого лаунчера. Он передаётся API и доверенным CDN через заголовок `x-api-key`, а не в URL. Если автор запретил стороннюю загрузку или API не предоставил ссылку, лаунчер не подставляет URL самостоятельно: файл отмечается как недоступный. Сборка с обязательным недоступным файлом не устанавливается неполной.

### Библиотека и перенос сборок

В настройках «Внешний вид» включи «Не закрывать лаунчер при запуске игры», чтобы продолжать пользоваться его окном во время игры. По умолчанию сохраняется прежнее поведение: окно скрывается до завершения Minecraft.

При переносе папки сборки показываются процент и объём скопированных данных, включая прогресс внутри больших файлов мира. Подсчёт и копирование выполняются в фоне; отмена удаляет незавершённую копию и сохраняет исходную сборку.

В разделе «Аккаунты» кнопка «Скин и плащ» открывает редактор Minecraft Java. На вкладке «Плащ» можно выбрать доступный аккаунту плащ или снять его, увидеть результат на персонаже и применить изменение к профилю. Используется тот же API Minecraft, что в [Modrinth](https://github.com/modrinth/code/blob/main/packages/app-lib/src/state/minecraft_skins/mojang_api.rs). Офлайн-аккаунты не могут изменять плащ в официальном профиле.

Нажми на сборку в библиотеке, чтобы открыть её контент, файлы, миры, журнал и статистику. Шестерёнка открывает окно настроек с разделами; здесь можно задать для этой сборки свою память, Java (исполняемый файл или папку JDK), JVM-аргументы, размер окна и режим полного экрана. Память и аргументы по умолчанию наследуются из общих настроек, Java подбирается автоматически, а режим экрана берётся из игры. Кнопка «Использовать общие настройки» сбрасывает только параметры запуска этого профиля; его контент и миры сохраняются. Установленные моды, шейдеры и ресурспаки можно искать, включать, выключать, удалять и добавлять из файлов. Кнопка установки в каталоге открывает версии проекта: перед скачиванием выбери конкретный выпуск сборки и версию Minecraft.

Для переноса выбери «Новая сборка» → импорт из папки. Можно указать отдельный профиль, его папку `.minecraft` или общую папку `instances` / `profiles`. Лаунчер определяет метаданные Prism/MultiMC, Modrinth (JSON и SQLite), CurseForge и ATLauncher. Если метаданных нет, версию и загрузчик можно указать в окне переноса. Копируется вся папка игры, включая нестандартные каталоги сборки, логи и миры; учётные данные остаются в исходном лаунчере. Исходные файлы не изменяются.

Счётчики времени Prism/MultiMC и Modrinth добавляются в общую статистику и на страницу сборки. Сохранившиеся логи восстанавливают календарь активности; общее время не считается дважды. Без поминутной истории из исходного лаунчера недостающие часы показываются только в общем счётчике.

### Организация библиотеки

Сборки можно добавлять в избранное, объединять в группы и дублировать вместе с мирами, модами и личными настройками. Копия получает свою папку и новую историю запусков. В режиме «Выбрать» доступны группировка, избранное и удаление нескольких сборок с подтверждением.

Нажми на иконку сборки или выбери «Изменить иконку» в меню. Редактор предлагает восемь объёмных значков, семь фонов и загрузку PNG/JPEG/WebP до 8 МБ. Изображение копируется в папку профиля и не зависит от исходного файла.

Папку профиля или архив сборки можно перетащить в библиотеку. Во вкладке «Контент» перетаскиваются моды `.jar`, ресурспаки и шейдеры `.zip`; флажки позволяют выполнять массовые действия.

Настройки лаунчера открываются поверх текущей страницы. Раздел «Язык» содержит поиск по родному названию, переведённому названию и коду локали. Доступны 50 локалей, включая английский США/Великобритании, испанский Испании/Латинской Америки, португальский Бразилии/Португалии и два варианта китайского. По умолчанию используется английский США; сохранённый выбор языка сохраняется.

Переводы встроены в приложение и не требуют сети. Новые словари подготовлены машинным переводом и пока не вычитаны носителями. Правила обновления и источники описаны в `src/main/resources/i18n/README.md`.

Интерфейс использует Onest и подмножества Noto для остальных письменностей. Шрифты и лицензии SIL OFL встроены в `src/main/resources/fonts`; для арабского, персидского и иврита применяется направление справа налево.

Фильтры снапшотов и alpha/beta действуют в выборе Minecraft, создании/импорте профилей и версиях проектов каталога. Готовые профили остаются в библиотеке. Автоматический FPS-буст удалён; ранее установленные им моды сохраняются как обычный управляемый контент.

### Скин лицензионного аккаунта

Кнопка «Скин и плащ» в аккаунтах открывает страницу «Скины», также доступную слева. PNG 64×64 или 64×32 до 1 МБ можно добавить кнопкой или перетаскиванием файла. Коллекция хранится в `.aw/skins`, переживает перезапуск и поддерживает изменение порядка плиток. В редакторе доступны название, замена текстуры, широкие/тонкие руки и плащи аккаунта. Сохранение пресета меняет только локальную библиотеку; для изменения профиля нажми «Применить». Сброс предпросмотра и удаление пресета не изменяют текущий скин Minecraft.

Превью показывает объёмного персонажа с перспективой, освещением и внешним слоем текстуры. Перетаскивание вращает модель, колёсико меняет масштаб, двойной щелчок сбрасывает вид, один щелчок запускает приветствие. Кнопки над моделью переключают внешний слой, анимацию и сброс вида; стрелки и клавиши +/− работают после фокуса на превью. Фоновая анимация ограничена 30 обновлениями в секунду и останавливается при потере фокуса окна или закрытии редактора. Движок использует существующий Skia-контекст Compose без дополнительного браузера и зависимостей. Камера и визуальная подача сверены с открытой реализацией Modrinth; модель, движение и отрисовка реализованы в AW самостоятельно.

Изменение отправляется в профиль Minecraft Java через официальный сервис Minecraft Services с токеном этого аккаунта. Скин становится общим для остальных лаунчеров и серверов; игра может показать его после повторного входа. Перед записью проверяется UUID профиля, токены не попадают в сообщения об ошибках, перенаправления для авторизованных запросов отключены. Обновление не переключает выбранный аккаунт. Офлайн-профили этим API не пользуются. Разработка проверяет загрузку поддельным HTTP-клиентом; реальные аккаунты тестами не изменяются.

### Производительность интерфейса

На Windows пользовательский заголовок подключён к системному перемещению и изменению размера через Win32 hit testing. Это сохраняет нативную привязку окна к краям, Win+стрелки, двойной щелчок по заголовку, его системное меню и возможность Aero Shake, если она включена в настройках Windows. Кнопка разворачивания возвращает HTMAXBUTTON для меню Snap Layouts на Windows 11. Минимальный размер — 600×420; в узком окне боковая колонка уведомлений скрывается, фильтры переносятся, а статистика показывается в две колонки. Заголовок визуально остаётся собственным. На других ОС используется прежнее перетаскивание Compose.

Настройки отображаются внутри главного окна: дополнительное системное окно и контекст отрисовки не создаются. Появление и закрытие панели используют прозрачность и сдвиг; текст не масштабируется. При переключении страниц повторно используются до трёх неактивных наборов UI-узлов, состояние поиска и прокрутки сохраняется. Закрытые страницы деактивируются. Календарь активности рисуется одним полотном с одним обработчиком наведения. Метаданные профилей и индексы истории повторно используются до изменения данных.

Для сравнения CPU-затрат есть `gradlew benchmarkUi -PnoDeploy '-PbenchmarkReport=ui-performance.tsv'`. Он использует отдельную папку пользователя, 24 синтетических профиля и 960 сессий; не запускает игру и не обращается к сети. После трёх прогревочных проходов выполняются шесть измерительных проходов. Отчёт находится в `build/ui-performance.tsv`.

На машине разработки при 1280×780 медиана первого вызова отрисовки вкладки активности снизилась с 151,91 до 40,82 мс, библиотеки — с 142,62 до 113,17 мс. Это программная отрисовка на CPU; показатели не являются FPS аппаратно ускоренного окна. Даже после оптимизации программные кадры остаются медленнее 16,7 мс. Текущий стек остаётся Kotlin/Compose; смена движка интерфейса в этот патч не входит.

### Совместная разработка

Нужны Git и JDK 21. Исходники доступны всем, доступ к приватным репозиториям не требуется.

```powershell
git clone https://github.com/AlpheusWorld/AWLauncher-releases.git
cd AWLauncher-releases
$env:JAVA_HOME = 'C:/Program Files/Java/jdk-21'
.\gradlew.bat test -PnoDeploy
.\gradlew.bat run -PnoDeploy
```

Укажи в `JAVA_HOME` путь к своему JDK 21. Gradle уже включён в проект: отдельно устанавливать его не нужно. Параметр `-PnoDeploy` позволяет собирать и проверять проект без замены установленной копии лаунчера.

Для изменений создавайте отдельные ветки и отправляйте pull request в `main`. Перед новой работой обновляйте `main` командой `git pull --ff-only`. GitHub Actions проверяет тесты и сборку приложения для Windows.

### Локальная сборка

Для сборки нужен JDK 21.
Сборка проверялась с JDK 21; если на компьютере по умолчанию выбран более новый JDK, запусти Gradle с `JAVA_HOME`, указывающим на JDK 21.

```powershell
.\gradlew.bat test
.\gradlew.bat run
```

Релизная сборка Windows требует `AW_MS_CLIENT_ID` и `AW_SIGNER_THUMBPRINT`:

```powershell
.\gradlew.bat packageReleaseDistributionForCurrentOS
```

Установщик `.exe` открывает квадратное тёмное окно 600×600 с логотипом AWLauncher по центру. Во время установки внизу показываются тонкая полоса и текущий процент. На последнем экране есть галочка «Запустить сейчас» и кнопка «Завершить»: если снять галочку, установщик закроется без запуска лаунчера. Папку и ярлык можно настроить перед установкой. Прогресс, отмена и откат работают через Windows Installer; закрытие окна или Escape во время установки запрашивают отмену. MSI остаётся пакетом для установки и обновления; игровые данные в `.aw` в него не входят.

Для локальной проверки установщика без замены установленного лаунчера:

```powershell
.\gradlew.bat packageDistributionForCurrentOS -PnoDeploy
```

Ресурсы установщика находятся в `branding/installer`. `Setup.cs` компилируется встроенным в Windows компилятором .NET Framework и использует WinForms, как существующий экран обновления. В `.exe` включены MSI, логотип и шрифты; дополнительных загрузок для установки не требуется. MSI собирается существующим jpackage/WiX из образа приложения с JDK 21. Его ресурсы подключает `prepareInstallerResources`, обходя очистку `--resource-dir` в Compose 1.7. Обложки резервных MSI-диалогов можно пересоздать через `python branding/make_assets.py --installer` (Pillow нужен только для пересоздания графики).

Для проверки отрисовки настоящих элементов установщика запусти готовый `.exe` с `--render welcome путь.png` (также доступны `options`, `progress`, `success`, `confirm`, `error`). Необязательный четвёртый аргумент задаёт желательный масштаб, например `--render success путь.png 1.5` для 150%. Если окно не помещается на выбранном мониторе, весь интерфейс равномерно уменьшается, сохраняя квадратную форму и доступ к кнопкам. `--test-extract папка` проверяет встроенный MSI и его прогресс через административную распаковку, не регистрируя приложение в системе. MSI сохраняется в пользовательском кэше `AlpheusWorld/InstallerCache`, чтобы восстановление файлов не зависело от временной папки.

При ошибке упаковки добавь `-PinstallerVerbose`, чтобы получить вывод WiX. CI собирает оба установщика; релизный workflow подписывает и публикует `.msi` и `.exe`, а файл обновления продолжает указывать на `.msi`.

Папка данных — `.aw`. В ней хранятся аккаунты, настройки, игровые папки и сборки.

Компоновка выбора скина изучена по [Modrinth App](https://github.com/modrinth/code/blob/main/apps/app-frontend/src/pages/Skins.vue). Реализация на Kotlin/Compose и рендерер принадлежат AWLauncher; код Vue и фирменные ресурсы Modrinth не включены. Стандартные текстуры загружаются с `textures.minecraft.net` и не входят в установщик.
