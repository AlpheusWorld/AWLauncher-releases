## Minecraft под тебя

AWLauncher — лаунчер Minecraft Java с открытым исходным кодом под MIT. Здесь находятся код приложения, тесты, файлы сборки, официальные релизы и материалы поддержки.

| Возможность | Что можно делать |
| --- | --- |
| Сборки | Создавать профили, переносить сборки из других лаунчеров, объединять их в группы |
| Контент | Искать проекты на Modrinth, выбирать версии, включать моды, ресурспаки и шейдеры |
| Очередь загрузок | Добавлять несколько проектов, видеть прогресс, выбирать следующую задачу, отменять и повторять загрузки |
| Аккаунты | Входить через Microsoft, менять скин и выбирать доступные аккаунту плащи |
| Скриншоты | Смотреть снимки игры внутри лаунчера, искать и открывать их в полном размере |
| Статистика | Следить за игровым временем, запусками и активностью |
| Обновления | Получать новые версии из лаунчера с проверкой подписи и целостности |

## Установка

1. Скачай **AWLauncher-Setup.exe** по кнопке выше.
2. Запусти установщик и выбери папку при необходимости.
3. Войди в Microsoft-аккаунт с Minecraft Java или добавь офлайн-профиль для совместимых серверов.

Нужна **Windows 10 или 11, 64-бит**. Среда Java для самого лаунчера входит в установщик; подходящую Java для игры лаунчер подбирает отдельно. Файлы Minecraft в дистрибутив не входят.

## Обновления без переустановки вручную

При запуске AWLauncher проверяет новую версию. Если она доступна, в заголовке появляется кнопка обновления. Проверить её вручную можно в **«Настройки → О лаунчере»**.

После загрузки лаунчер проверяет подпись описания релиза, размер и SHA-256 установщика, закрывается для установки и открывается снова. Обновление сохраняет текущую папку, игровые сборки и настройки. Если Minecraft запущен, сначала заверши игру.

**Для старых сборок 1.0.1 и 1.6.7 нужен один ручной переход на 1.0.3.** В них ещё нет нового ключа проверки обновлений. Далее новые выпуски можно ставить из лаунчера.

Первый установщик пока не имеет доверенного Authenticode-сертификата Windows, поэтому Windows может показывать предупреждение об издателе. Проверка подписи обновлений ключом AWLauncher работает отдельно от подписи Windows. Подробнее — в [SECURITY.md](SECURITY.md).

## Нужна помощь

В версии 1.0.4 раздел **«Загрузки»** открывается кнопкой со стрелкой вниз слева. Установки из каталога добавляются в общую очередь. Пауза позволяет текущей задаче завершиться и откладывает следующие; ошибка одной загрузки не блокирует остальные. Через меню сборки → **«Скачать файлы»** можно подготовить Minecraft без запуска игры.

Открой [обращение об ошибке](https://github.com/AlpheusWorld/AWLauncher-releases/issues/new/choose) и укажи версию лаунчера, Windows и шаги, после которых появилась проблема. Обращения по проекту и правам на материалы: **contact@awlauncher.ru**.

## Сборка из исходников

Нужны Windows x64, Git и JDK 21. Gradle включён в проект.

```powershell
git clone https://github.com/AlpheusWorld/AWLauncher-releases.git
cd AWLauncher-releases
$env:JAVA_HOME = 'C:/Program Files/Java/jdk-21'
.\gradlew.bat test -PnoDeploy
.\gradlew.bat run -PnoDeploy
```

Для установщиков выполни `.\gradlew.bat packageDistributionForCurrentOS -PnoDeploy`. Укажи свой путь к JDK в `JAVA_HOME`. Параметр `-PnoDeploy` сохраняет установленную копию лаунчера.

Код приложения находится в `src/main`, тесты — в `src/test`, ресурсы установщика — в `branding/installer`. Изменения можно предложить через pull request; GitHub Actions проверяет тесты и сборку.

`.gitignore` содержит общие правила для участников проекта: исключает сборки, кэши, данные IDE и локальные секреты. Сам файл хранится в Git, чтобы эти правила действовали у всех.
