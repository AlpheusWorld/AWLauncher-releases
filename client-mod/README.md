# AWAssistant

Клиентский помощник AWLauncher для поиска правил серверов внутри Minecraft. Использует нативный рендер игры, поддерживает кириллицу, поиск по номеру, названию, описанию и ключевым словам, категории, серверы и подробное описание с наказанием.

## Использование

Открой помощник клавишей **F8**. Привязку можно изменить в Minecraft → Управление → AWAssistant. Введи запрос: компактная панель раскроет результаты и описание выбранного правила. Стрелки вверх/вниз выбирают результат; Enter возвращает начало описания; Escape сначала закрывает список или очищает запрос, затем закрывает помощник. F8 закрывает помощник сразу. Списки и описания прокручиваются колёсиком мыши. В меню справа можно отключить анимации и размытие. Размер панели не зависит от GUI Scale; Onest отрисовывается со сглаживанием через ограниченный кэш текстовых текстур игры.

## Правила серверов

Наборы находятся в `config/awassistant/rules` внутри папки сборки. Кнопка «Папка правил» открывает эту папку; после добавления файла нажми «Обновить». JSON можно перетащить прямо в окно помощника.

Структура набора:

```json
{
  "id": "server-id",
  "name": "Название сервера",
  "addresses": ["play.example.org"],
  "sourceUrl": "https://example.org/rules",
  "rules": []
}
```

В массив `rules` добавляются объекты с полями `number`, `title`, `category`, `description`, `sanction`, `keywords`. Поля `number`, `title` и `description` обязательны; `keywords` — массив строк. Номера должны быть уникальны в пределах сервера. Полный текст и наказание берутся из актуального источника владельца сервера.

Встроены пять русскоязычных проектов: SpookyTime, ReallyWorld, FunTime, MineBlaze (общие правила) и HolyWorld (классическая анархия). Это подборка популярных проектов, а не неизменный рейтинг онлайна. При открытии доступны короткие авторские памятки; мод асинхронно получает полный текст с официальных страниц и сохраняет его в `config/awassistant/official-cache`. Свежий кэш используется в течение суток; «Обновить правила» принудительно проверяет источники. Полный текст серверов не распространяется в JAR.

Если сайт недоступен или изменил разметку, прежний набор сохраняется. Название «памятка» и нижняя подсказка обозначают сокращённый набор; кнопка «Источник» открывает оригинал. Сроки наказания появляются только там, где они явно указаны владельцем сервера. Локальные JSON имеют приоритет и не перезаписываются обновлением. Ошибка одного файла не скрывает остальные наборы; импорт проверяет данные до замены.

Окно перетаскивается за верхнюю шапку. Положение, анимации и размытие сохраняются в `config/awassistant/ui.json`; в меню есть «Вернуть в центр». Панель остаётся в пределах экрана при изменении масштаба.

## Поддержка и установка

Доступны отдельные JAR для Fabric 26.1.2 и Fabric 26.3, Java 25. Минимальные модули Fabric API включены в JAR; Minecraft и его игровые файлы в мод не включены. В AWLauncher → Настройки → Игра можно отключить автоматическое скачивание. Уже установленный мод отключается в списке модов сборки. Лаунчер не заменяет вручную установленный или отключённый AWAssistant и не меняет загрузчик сборки.

## Сборка

Используется Gradle wrapper лаунчера, запущенный на JDK 21, и отдельный компилятор JDK 25:

```powershell
$env:JAVA_HOME = 'C:/path/to/jdk21'
$env:AW_JAVA25_HOME = 'C:/path/to/jdk25'
.\gradlew.bat -p client-mod build -PgameVersion=26.1.2
.\gradlew.bat -p client-mod build -PgameVersion=26.3
```

Современные версии Minecraft не обфусцированы; мод компилируется против официального игрового JAR, который не входит в результат сборки. Отдельный `smokeJar` — тестовый мод проверки интерфейса, он не распространяется с рабочим AWAssistant.
