# AWAssistant

Встроенный клиентский помощник AWLauncher: правила серверов, поиск по ситуации, избранное и настраиваемый HUD. Работает через нативный интерфейс Minecraft; игровые файлы в мод не включены.

## Управление

**F8** открывает помощник. Нажми поиск или **Ctrl+K**, затем введи действие, ситуацию или номер пункта. Без фокуса поля текст не вводится. Стрелки выбирают результат, Enter возвращает описание к началу. Escape закрывает список или очищает запрос, затем закрывает окно. F8 закрывает окно сразу. Клавиши меняются в Minecraft → Управление → AWAssistant.

Правила, избранное, история и изменения находятся в общей верхней навигации. Список и статья прокручиваются независимо. Наказание выделяется при наличии в источнике; заголовки с подпунктами показывают их текст. Закладка сохраняет пункт, соседняя кнопка копирует текст. Ссылка «Правила на сайте» открывает официальный источник.

Окно перетаскивается за область логотипа. Кнопка с ползунками открывает настройки: анимации, размытие, поиск и центрирование окна. Положение сохраняется в config/awassistant/ui.json. Масштаб рассчитывается по размеру окна независимо от GUI Scale Minecraft. Во всех разделах используются Onest Medium/SemiBold, сглаженные иконки и ограниченный кэш текстовых текстур.

## Правила серверов

Встроены SpookyTime, ReallyWorld, FunTime, MineBlaze (общие правила) и HolyWorld (классическая анархия). Это подборка популярных русскоязычных проектов, а не неизменный рейтинг онлайна.

При открытии доступны короткие авторские памятки. Мод в фоне получает полный текст с официальных страниц и сохраняет его в config/awassistant/official-cache. Свежий кэш используется сутки; «Проверить правила» принудительно проверяет источники. Полные тексты серверов не распространяются в JAR.

Если сайт недоступен или изменил разметку, прежний набор сохраняется. Название «памятка» обозначает сокращённый набор. Наказание показывается только там, где оно явно указано владельцем сервера. Отсутствие результата поиска не означает, что действие разрешено.

Свои наборы можно добавить в config/awassistant/rules или перетащить JSON в окно помощника:

~~~json
{
  "id": "server-id",
  "name": "Название сервера",
  "addresses": ["play.example.org"],
  "sourceUrl": "https://example.org/rules",
  "rules": []
}
~~~

Правила содержат поля number, title, category, description, sanction и keywords. Номер, название и описание обязательны; номера уникальны в пределах сервера. Keywords — поисковые метки, которые не меняют исходный текст. Локальные наборы имеют приоритет и не перезаписываются обновлением. Некорректный импорт не заменяет рабочий файл.

## Избранное и история

Закладки и последние 30 запросов хранятся отдельно для каждого сервера. Запрос можно повторить или удалить историю. При успешной проверке официального источника сохраняются дата проверки и до десяти последних редакций с полным старым и новым текстом и наказанием. Первая загрузка создаёт исходное состояние без уведомления об изменении всех пунктов.

## Локальный поиск по смыслу

Включается в настройках. Первая поисковая фраза скачивает примерно **81 МиБ**: модель INT8, словарь и ONNX Runtime. До включения ничего не скачивается. Размеры и SHA-256 закреплены в коде; кэш используется повторно между сборками.

Используется готовый encoder [sergeyzh/rubert-mini-frida](https://huggingface.co/sergeyzh/rubert-mini-frida), а не генеративная модель. Запросы и документы получают разные поисковые префиксы, используется mean pooling. Длинные правила индексируются перекрывающимися фрагментами вместе с заголовками. BM25, формы слов, поисковые метки и смысловая близость поступают в небольшой классификатор релевантности, обученный на размеченных парах «вопрос — пункт». Слабые совпадения отбрасываются. Encoder мы не дообучали и не выдаём за собственную нейросеть.

Вопросы не передаются внешним сервисам. Подготовка индекса выполняется в фоне. Один вычислительный поток работает без активного ожидания; после 90 секунд простоя сессия модели освобождается. При выключении освобождаются сессия и индекс в памяти. Ответ содержит исходные правила и наказания, без сгенерированных условий.

Происхождение и лицензия: [search-model-NOTICE.txt](src/main/resources/assets/awassistant/search-model-NOTICE.txt). Скрипт tools/prepare_assistant_search.py воспроизводит закреплённый INT8-файл. Для проверки есть tools/evaluate_assistant_search.py, Java-проверка SearchQualitySmoke и tools/train_assistant_ranker.py. Размеченные вопросы находятся в src/test/resources/search-evaluation.json; коэффициенты — в assets/awassistant/search-ranking.json.

При обучении исключаются запросы с пометкой holdout; порог подбирается перекрёстной проверкой по серверам. Контрольные вопросы использовались при разработке и не являются независимым внешним бенчмарком. Модель может пропустить нужный пункт; оригинальные правила доступны по ссылке внизу окна.

## HUD

**F9** или кнопка HUD в шапке открывает редактор. FPS, пинг, координаты, броня и эффекты включаются отдельно. Карточка выбирает элемент, переключатель меняет его видимость. Ниже доступны предпросмотр, размер и сброс выбранного элемента. «Разместить на экране» открывает игровой холст: перетаскивай элементы и меняй размер колёсиком над ними. Tab возвращает каталог.

По умолчанию всё выключено. Положение и размер сохраняются автоматически; сброс сохраняет выбор включённых элементов. Используются тот же Onest и штатные текстуры предметов Minecraft.

## Установка и сборка

Отдельные JAR поддерживают **Fabric 26.1.2 и Fabric 26.3, Java 25**. Минимальные модули Fabric API включены в JAR. В AWLauncher → Настройки → Игра можно отключить автоматическое скачивание. Уже установленный мод отключается в списке модов сборки. Лаунчер не заменяет вручную установленный или отключённый AWAssistant и не меняет загрузчик сборки.

Используется Gradle wrapper лаунчера, запущенный на JDK 21, и отдельный компилятор JDK 25:

~~~powershell
$env:JAVA_HOME = 'C:/path/to/jdk21'
$env:AW_JAVA25_HOME = 'C:/path/to/jdk25'
.\gradlew.bat -p client-mod build -PgameVersion=26.1.2
.\gradlew.bat -p client-mod build -PgameVersion=26.3
~~~

Современные версии Minecraft не обфусцированы; официальный compile-only JAR не входит в результат. Отдельный smokeJar проверяет интерфейс в настоящем клиенте и не распространяется с рабочим модом.
