# AWLauncher 1.0.23

Список установленного контента открывается без ожидания проверки каталогов

- Локальные файлы показываются без предварительного чтения всех архивов целиком
- Названия проектов и сведения об обновлениях подгружаются в фоне, отдельно для каждой категории
- Контрольные суммы неизменённых файлов сохраняются между запусками; изменённые файлы проверяются заново
- Кнопка сайта и ссылка на логотип в Discord Rich Presence ведут на https://alpheusworld.ru/

Доступно для Windows и Linux x64. Обновление распространяется через подписанные фиды лаунчера
