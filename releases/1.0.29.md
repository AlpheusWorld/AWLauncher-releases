# AWLauncher 1.0.29

## История изменений сборки

- Во вкладке «История» сохраняются состояния перед обновлениями модов, обновлениями сборок и массовыми изменениями контента
- Для изменений отображаются прежние и новые версии проектов
- Кнопка «Вернуть рабочее состояние» восстанавливает последнее сохранённое состояние; можно выбрать и более ранний снимок
- Перед откатом автоматически сохраняется текущее состояние, чтобы можно было отменить восстановление
- Состояние можно сохранить вручную, а ненужные снимки — удалить; в истории указан занимаемый ими объём
- Сохранение миров включается отдельно и по умолчанию выключено
- При восстановлении снимка с мирами можно отдельно выбрать, возвращать ли прогресс миров
- Обычный откат сохраняет прогресс миров, возвращая моды, настройки, скрипты, ресурспаки, шейдеры и датапаки
- Перед восстановлением проверяется целостность снимка; при ошибке применения возвращаются прежние файлы
- Частично выполненные и отменённые изменения тоже оставляют доступный снимок для восстановления
