# AWLauncher 1.0.19

## CurseForge для всех пользователей

- Каталог CurseForge работает без ручного ввода API-ключа
- Поиск, страницы проектов, версии, зависимости и скачивание доступны через сервер AWLauncher
- Общий API-ключ хранится только в серверном секрете и не включается в исходники или установщики
- Сохраняются ограничения авторов на загрузку через сторонние лаунчеры и проверка контрольных сумм файлов
- Существующая настройка собственного ключа продолжает работать

Обновление доступно через встроенное предложение лаунчера или «Настройки» → «О программе» → «Проверить обновления». Данные профилей и локальная настройка собственного ключа сохраняются
