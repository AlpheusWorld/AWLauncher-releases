# AWLauncher 1.0.5

- Изменение версии Minecraft в существующей сборке без создания второго профиля
- Общая проверка модов по хешам на Modrinth для выбранной версии и текущего загрузчика
- Выбор для каждого мода без совместимого выпуска: оставить включённым или отключить
- Загрузка совместимых модов и необходимых зависимостей через общую очередь
- Сохранение имени, папки, истории, миров и конфигов сборки
- Резервные файлы модов и настроек в aw-migration-backups; автоматический откат при ошибке применения
- Защита от применения устаревшего плана, если файлы сборки изменились после проверки
- Сборки с вручную изменённой версией Minecraft больше не перезаписываются проверкой официальных обновлений сборки

Открой меню сборки → «Изменить версию Minecraft», выбери версию, нажми «Проверить моды» и просмотри результат. Моды без подтверждённой совместимости по умолчанию отключены; можно оставить нужные включёнными.

Обновление профиля не изменяет миры. Перед первым запуском мира на другой версии Minecraft сохрани резервную копию этого мира.
