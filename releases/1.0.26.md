# AWLauncher 1.0.26

## Исправления автообновления Windows

- Отдельное окно AWLauncher.Update.exe с фирменным значком и собственной группой в панели задач
- Перемещение за шапку, сворачивание, чёткая отрисовка при 100%, 150% и 200% и смене масштаба монитора
- Старый процесс сохраняет данные и больше не ждёт завершения фоновых служб без ограничения
- Истечение ожидания старого лаунчера не выдаётся за ошибку Windows Installer 1618
- Если Windows Installer занят, обновлятор ждёт и автоматически повторяет установку до пяти минут
- При ошибке окно остаётся открытым с действиями «Повторить» и «Открыть лаунчер»; повторный запуск обновления блокируется
- Переход к установке выполняется только после появления готового окна; для каждой попытки сохраняется отдельный журнал

Важное для перехода со старых версий: первое обновление запускается кодом уже установленного лаунчера. Если старое окно снова покажет 1618, установите этот выпуск через AWLauncher-Setup.exe. Новый обновлятор будет использоваться для следующих обновлений.
