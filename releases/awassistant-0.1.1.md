# AWAssistant 0.1.1

- Окно можно двигать за верхнюю шапку; положение, анимации и размытие сохраняются
- Переработаны шапка, поиск, результаты и область чтения; добавлены просмотр всех правил и возврат окна в центр
- Добавлены SpookyTime, ReallyWorld, FunTime, MineBlaze (общие правила) и HolyWorld (классическая анархия)
- Полный текст загружается с официальных страниц в фоне и сохраняется локально; короткие памятки доступны без сети
- Пользовательские наборы имеют приоритет и не перезаписываются при обновлении

Для ReallyWorld официальный форум на момент проверки отвечает HTTP 403: доступна сокращённая памятка с номерами пунктов и ссылкой на полные правила. Памятки явно отмечены в интерфейсе. Это подборка пяти популярных русскоязычных проектов, а не фиксированный рейтинг онлайна.

Отдельные файлы для **Fabric 26.1.2** и **Fabric 26.3**, **Java 25**, **Fabric Loader 0.19.3 или новее**. Минимальные модули Fabric API включены. Открытие — **F8**, привязка меняется в управлении Minecraft.

Лицензия кода — MIT. Полные тексты правил серверов не включены в распространяемые JAR.
