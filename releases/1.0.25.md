# AWLauncher 1.0.25

## AWAssistant 0.3.0

- Заново собраны окно правил, избранное, история, изменения и настройки: общая верхняя навигация, широкий поиск, отдельная область чтения, единые шрифты и иконки
- Окно сохраняет положение и масштабируется по размеру экрана; ввод работает только после выбора поисковой строки
- В редакторе HUD появились общий каталог пяти элементов, предпросмотр и отдельное размещение в игре с перетаскиванием и изменением размера
- Обновлён отключаемый локальный поиск: MiniFRIDA INT8, отдельные поисковые префиксы, полные фрагменты правил и обученный небольшой классификатор релевантности
- Добавлены поисковые метки для жаргона и названий действий, включая FunPay; обычный поиск лучше различает тему правила и случайные упоминания
- Исправлены ложное определение наказания из инструкции, потеря поисковых меток после обновления источника и показ ошибки чужого сервера в текущем окне
- Пункты-заголовки показываются вместе с подпунктами; исходные формулировки и сроки наказаний не придумываются

Поддерживаются Fabric 26.1.2 и 26.3, Java 25. Поиск по смыслу и каждый элемент HUD включаются отдельно. Модель скачивается только после включения поиска; вопросы обрабатываются локально.
