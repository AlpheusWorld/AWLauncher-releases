# AWLauncher 1.0.30

## Обязательные зависимости модов

- Установка и обновление модов используют общую проверку зависимостей для Modrinth и CurseForge
- Обязательные моды и их зависимости подбираются под версию Minecraft и загрузчик
- Учитывается конкретный выпуск зависимости, если он указан автором
- Подходящая выключенная зависимость включается; устаревшая заменяется совместимым выпуском
- При включении распознанного мода его обязательные зависимости тоже проверяются; локальные Fabric-зависимости можно включить вместе с ним
- Автоматическое исправление конфликтов также учитывает зависимости выбранного выпуска
- Для Fabric проверяются требования из самих JAR, включая диапазоны версий, альтернативные ID и встроенные библиотеки
- Новые файлы сначала загружаются и проверяются во временной папке; ошибка или отмена до применения сохраняет прежние моды
- Если обновление библиотеки нарушает требования установленного Fabric-мода, несовместимая комбинация не применяется
- Совпадающие ID модов и несовместимые обязательные выпуски не устанавливаются вместе

## Дополнительные моды и локальные файлы

- Необязательные зависимости отображаются отдельно в окне выпуска: их можно посмотреть и установить самостоятельно
- Добавляемые JAR распознаются по хешам; для найденного выпуска подбираются обязательные зависимости
- Неопознанные Fabric-моды проверяются по локальному описанию, включая требования к другим модам и версии Minecraft
- Если файл не распознан и его зависимости проверить нельзя, лаунчер предлагает установить мод через каталог
- Автоматические изменения сохраняются в истории сборки и доступны для отката
