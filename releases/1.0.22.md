# AWLauncher 1.0.22

Первый публичный выпуск для **Linux x64** — пакеты DEB и RPM

- Java для самого лаунчера включена в установщик
- Ссылки и папки открываются через системные приложения; поддерживаются ярлыки .desktop
- Microsoft-токены шифруются, ключ хранится в Secret Service; временная недоступность связки не стирает сохранённые токены
- Discord Rich Presence работает через Unix-сокеты, включая обычные пути Flatpak и Snap
- Для DEB и RPM публикуются отдельные подписанные фиды автообновлений с проверкой Ed25519, размера и SHA-256
- Установка обновления выполняется менеджером пакетов с подтверждением Polkit
- Linux-пакеты проходят тесты и проверку запуска установленного приложения в CI

Для запуска нужна графическая сессия X11 или XWayland. Данные сохраняются в ~/.aw. Для Windows доступны обычные установщики MSI и EXE
