# AWLauncher 1.0.24 · AWAssistant 0.2.0

- Необязательный локальный поиск правил по смыслу: RuBERT-tiny2 INT8, загрузка модели и среды только после включения; проверка SHA-256, один вычислительный поток, выгрузка сессии после простоя
- Избранные правила и последние запросы отдельно для каждого сервера, повтор поиска и очистка истории
- История изменений правил: полный текст до и после изменения, наказания и дата последней проверки официального источника
- Редактор HUD по F9: FPS, пинг, координаты, броня с прочностью и эффекты; отдельное включение, перемещение и масштаб каждого элемента
- Избранное и редактор HUD можно открывать во время загрузки правил
- AWAssistant 0.2.0 для Fabric 26.1.2 и 26.3 включён в каталог автозагрузки лаунчера

По умолчанию модель и HUD выключены. Для поиска по смыслу требуется примерно 78 МиБ дополнительных файлов; запросы обрабатываются локально. Первая загрузка правил создаёт исходное состояние для дальнейшего сравнения
