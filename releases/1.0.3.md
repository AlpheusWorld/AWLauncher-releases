# AWLauncher 1.0.3

- Проверка обновлений при запуске, каждые шесть часов и вручную в настройках
- Загрузка с процентами, скоростью и возможностью отмены
- Проверка цифровой подписи описания релиза, размера и SHA-256 установщика
- Установка в текущую папку и повторный запуск лаунчера
- Защита от повторной установки, старых версий и обновления во время игры
- Окно установки в тёмно-зелённом стиле AWLauncher

Для прежних версий 1.0.1 и 1.6.7 нужен один ручной переход через **AWLauncher-Setup.exe**. После этого новые версии доступны из лаунчера. Сборки, аккаунты и настройки сохраняются.

Описание обновления подписано ключом проекта; установщик пока не имеет доверенного Authenticode-сертификата Windows. Необходимые лицензии и исходники сторонних компонентов включены в выпуск.
