# AWLauncher 1.0.56

- Ускорено открытие сборок и повторный запуск Minecraft: локальный список содержимого появляется сразу, проверенные ресурсы повторно не перечитываются без изменений.
- Исправлена проверка встроенных зависимостей Fabric Loader, включая MixinExtras, чтобы Lithium не блокировал установку модов.
- Каталог показывает установленные проекты для выбранной сборки; обновлены иконки, переводы и адаптивная раскладка.
- Добавлен раздел друзей с прямым защищённым подключением по приглашению, автоматическим открытием порта через UPnP и отображением задержки. Хозяину нужны поддержка UPnP и публичный IPv4.
- Исправлено мигание статуса соединения при использовании английского языка.
