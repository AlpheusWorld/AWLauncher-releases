# AWLauncher 1.0.4

- Общая очередь загрузок модов, шейдеров, ресурспаков, сборок и файлов Minecraft
- Раздел «Загрузки» с прогрессом, скоростью, объёмом и состоянием каждой задачи
- Отмена текущей загрузки и удаление ожидающей задачи из очереди
- Выбор следующей задачи, пауза очереди и повтор неудачной загрузки
- Ошибка одной задачи не останавливает остальные
- Следующая задача ждёт завершения очистки отменённой загрузки
- Исходный код и дистрибутивы распространяются по MIT; лицензии сторонних компонентов сохранены

Пауза очереди позволяет завершиться текущей задаче, затем откладывает следующие. Скачать игровые файлы без запуска Minecraft можно через меню сборки → «Скачать файлы».

Обновление доступно из версии 1.0.3. Старые версии без ключа проверки требуют одного ручного перехода через установщик. Сборки и настройки сохраняются.
