# AWLauncher 1.0.8

- Новый отдельный раздел «Скины» с компоновкой выбора скина как в Modrinth: крупное превью слева и плитки справа
- Локальная библиотека PNG: добавление, замена текстуры, название, редактирование и удаление с подтверждением
- Девять стандартных персонажей Minecraft: Steve, Alex, Ari, Efe, Kai, Makena, Noor, Sunny и Zuri
- Перестановка сохранённых скинов перетаскиванием или через меню плитки
- Редактор модели рук и доступных аккаунту плащей с 3D-превью
- PNG можно перетащить в окно; выбор файла открывается в системном диалоге Windows
- Плитка меняет только предпросмотр. Изменения отправляются в Minecraft отдельной кнопкой «Применить»; «Сбросить» возвращает текущий вид
- Выбор аккаунта для редактирования не переключает аккаунт запуска Minecraft
- В компактном окне превью и коллекция располагаются одной прокручиваемой страницей
- Библиотека сохраняется между запусками; её данные и PNG обрабатываются вне потока интерфейса

Экран реализован на Kotlin/Compose с 3D-рендерером AWLauncher. Код Vue и фирменные ресурсы Modrinth в дистрибутив не включены; лицензия AWLauncher остаётся MIT.

Обновление доступно из лаунчера. Настройки, аккаунты, сборки и игровая история сохраняются.
