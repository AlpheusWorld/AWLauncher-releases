# AWLauncher 1.0.27

AWAssistant убран из лаунчера.

- Удалены автоскачивание и настройка встроенного помощника
- При следующем запуске сборки копия мода, автоматически установленная лаунчером, отключается без удаления файла
- Миры, настройки и ручные моды сохраняются; вручную заменённый AWAssistant не изменяется
- Исходники мода, его поисковой модели и шаги их сборки удалены из текущего проекта
- Новые релизы больше не содержат JAR-файлы AWAssistant; для сборки лаунчера достаточно JDK 21

Отключённая копия остаётся в mods с расширением .jar.disabled. После отключения пользователь может самостоятельно включить её как обычный мод.
