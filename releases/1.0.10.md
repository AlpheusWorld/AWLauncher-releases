# AWLauncher 1.0.10

- Заголовок текущего набора скинов закрепляется при прокрутке, чтобы набор можно было свернуть без возвращения наверх
- При раскрытии и сворачивании сохраняется положение заголовка; закрытие последнего набора не переносит пользователя к предыдущим скинам
- Поиск в каталоге скинов начинает показ результатов сверху
- Пресеты ОЗУ и выбора темы получили видимые обводки, выбранный вариант выделен чётким зелёным контуром
- Усилены границы полей памяти, Java, JVM и размера окна, включая настройки отдельных сборок
- Между переключателями Discord и списка версий добавлены последовательные разделители; границы блоков настроек стали заметнее

Обновление доступно из лаунчера. Настройки, аккаунты, сборки и коллекция скинов сохраняются.
