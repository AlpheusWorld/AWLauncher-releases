# AWLauncher 1.0.55

- Лаунчер использует Rust на Windows и Linux. Установщики больше не включают JVM лаунчера. Нужную Java для Minecraft лаунчер подбирает при установке игры.
- Добавлен импорт установленных профилей из Prism, MultiMC, Modrinth App, CurseForge и ATLauncher.
- Discord Rich Presence подключается из Tauri. Кнопка «Друзья» остаётся недоступной.
- Возвращены иконки Modrinth и CurseForge в списке установленного контента.
- Из списка серверов при запуске удаляется только старая запись VirtusMine.

На Ubuntu проверены запуск установленного пакета, импорт профиля, восстановление снимка и запуск Minecraft 1.21.1.
