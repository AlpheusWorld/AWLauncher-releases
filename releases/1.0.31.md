# AWLauncher 1.0.31

## Игра с друзьями

- Новая вкладка «Друзья»: постоянный код игрока, заявки с подтверждением, список друзей и статусы присутствия
- Новые сообщения включены во все языковые словари; обновлены встроенные шрифты для новых символов
- Приглашения в открытый мир с уведомлениями в лаунчере, выбором сборки и проверкой версии Minecraft, загрузчика и состава модов
- Игра с друзьями по умолчанию включена; её можно выключить в общих настройках
- На поддерживаемых сборках Fabric, Quilt, Forge и NeoForge автоматически устанавливаются e4mc и необходимые зависимости через существующий менеджер модов с проверкой контрольных сумм
- Хозяин запускает свой мир и выбирает «Открыть для сети», затем приглашает друга из лаунчера; выделенный игровой сервер и ручное открытие портов не нужны
- Мир работает на компьютере хозяина. e4mc использует прямое P2P-соединение, когда это возможно, и свою инфраструктуру ретрансляции при необходимости
- Сервис AWLauncher доставляет заявки, статусы и приглашения; игровые миры и файлы сборок туда не загружаются
- Профиль друзей хранится на устройстве в защищённом виде. Microsoft-токены не передаются в сервис друзей
- При выключении функции установленный лаунчером сетевой мод отключается на следующем запуске Minecraft; вручную установленные моды не удаляются
- Для неподдерживаемой версии Minecraft или загрузчика автоматическая установка сетевого мода пропускается с уведомлением; в Vanilla он не устанавливается

## Исправление обновления Windows

- Исправлена передача вложенных кавычек из Java нативному окну обновления, приводившая к ошибке Windows Installer 1639
- Если уже установленная старая версия продолжает показывать 1639, один раз запусти AWLauncher-Setup.exe из этого релиза: исправленный обработчик начнёт работать после установки

## Ограничения подключения

- Хозяин должен оставаться в мире и быть подключён к интернету; адрес меняется при создании нового сеанса, но код друга остаётся постоянным
- Состояние сеанса определяется по событиям Minecraft и сообщениям установленного e4mc; отказ обычного TCP-ping не отключает работающее P2P-подключение
- Доступность соединения зависит от e4mc и сети игроков; для модифицированного мира могут потребоваться одинаковые сборки
- Приглашённый получает адрес мира. Не передавай его посторонним; для прекращения доступа закрой мир или выполни `/e4mc stop`
