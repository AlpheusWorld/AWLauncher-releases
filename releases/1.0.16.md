# AWLauncher 1.0.16

- В настройках сборки появился выбор версии Fabric и Quilt Loader: например, 0.19.5 вместо закреплённой при импорте 0.19.3.
- Выбранная версия сохраняется отдельно для этой сборки и используется при запуске, скачивании файлов и переустановке. Кнопка «Применить Loader» сохраняет выбор; нужный Loader загружается при следующем запуске.
- Кнопка «Обновить список» получает свежие версии Loader. Список сортируется по номеру версии, а кэш больше не хранится до закрытия лаунчера.
- Настройки памяти, моды, миры и история сборки сохраняются. При смене версии Minecraft отдельный выбор Loader сбрасывается.

После обновления открой настройки нужной сборки → «Версия Loader» → выбери 0.19.5 → «Применить Loader» → запусти игру.
