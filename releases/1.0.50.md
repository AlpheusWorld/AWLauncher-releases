# AWLauncher 1.0.50

- Интерфейс на Rust встроен в приложение. Проверенный JVM-движок остаётся для Minecraft, аккаунтов, проверки зависимостей и установки файлов.
- Каталоги Modrinth и CurseForge: сетка карточек, поиск, сортировка, категории и страницы результатов.
- Страницы проектов: описание с форматированием, ссылками и изображениями, совместимость, выбор версии, список изменений и галерея.
- Очередь загрузок: прогресс, скорость, пауза следующих задач, отмена и повтор после ошибки.
- Страница сборки: контент, переключение и удаление с историей, файлы, миры, журнал, статистика, скриншоты и восстановление снимков.
- Настройки сборки, переименование, копирование, импорт локального контента, экспорт .mrpack и ярлыки.
- Подключены языковые словари лаунчера, переводы динамических подписей и резервные шрифты для описаний проектов.
- Раздел «Друзья» в этой версии недоступен.

- В Linux-пакеты добавлены зависимости клавиатуры X11 и OpenGL для запуска нового интерфейса.
