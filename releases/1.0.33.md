# AWLauncher 1.0.33

## Окно обновления Windows

- Убрана рамка вокруг кнопки сворачивания, включая состояние с фокусом клавиатуры
- В обычном состоянии остаётся аккуратный значок; фон появляется при наведении или навигации с клавиатуры
- Текст рисуется с повышенным разрешением и сглаживается до текущего масштаба Windows без цветной бахромы
- Размеры, расположение элементов, сворачивание, перетаскивание и восстановление после ошибки сохранены
- Статичная часть окна кэшируется и не пересоздаётся на каждом кадре анимации

Новое окно используется после установки этой версии. Переход со старой версии ещё запускается её прежним обработчиком обновления
