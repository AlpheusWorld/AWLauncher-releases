# AWLauncher 1.0.11

## AWAssistant — поиск правил внутри Minecraft

- Собственный клиентский мод с нативным интерфейсом игры: компактная строка поиска раскрывается в список результатов и карточку выбранного правила
- Кириллица, поиск по номеру, названию, ключевым словам, описанию и наказанию; отдельные наборы серверов и категории
- Плавное раскрытие панели, подсветка, переключение результатов и независимая прокрутка обеих колонок
- Копирование правила, управление мышью и стрелками, поддержка масштаба интерфейса Minecraft
- Открытие по **F8**; клавиша меняется в настройках управления Minecraft
- Наборы правил загружаются из JSON в `config/awassistant/rules`; файл можно перетащить в окно помощника

Первый выпуск поддерживает **Fabric 26.1.2 и 26.3**, Java 25 и Fabric Loader 0.19.3 или новее. Для каждой версии выпущен отдельный JAR. Минимальные необходимые модули Fabric API уже включены. Другие версии и загрузчики пока не поддерживаются.

Запись AresMine содержит адрес и официальный источник, без выдуманных правил. Пока проверенный JSON не добавлен, показывается понятное пустое состояние.

## Интеграция с лаунчером

AWAssistant автоматически скачивается перед запуском поддерживаемой сборки. Это можно отключить в **Настройки → Игра → Клиентский мод AWAssistant**. Переключатель останавливает новые скачивания; уже установленный мод отключается в списке модов сборки.

Лаунчер проверяет размер и контрольные суммы файла, использует локальный кэш и не заменяет вручную установленный или отключённый мод. Если скачивание не удалось, игра продолжает запускаться. Сборки на неподдерживаемых версиях остаются без изменений. Старый или неизвестный Fabric Loader не получает несовместимый мод автоматически.

Код мода опубликован вместе с исходниками лаунчера под MIT; лицензии Fabric API и Onest сохранены. AWAssistant — независимый проект, не связанный с LabyMod, Mojang или Microsoft.

Обновление доступно из лаунчера. Настройки, аккаунты, сборки и коллекция скинов сохраняются.
