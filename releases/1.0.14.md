# AWLauncher 1.0.14

- Исправлено ложное требование KotlinLangForge для Fabric при установке универсального Zoomify
- Зависимости, которые поддерживают только другой загрузчик, не блокируют установку подходящего мода
- При ошибке отдельного мода во время переноса сборки открывается выбор «Отключить этот мод и продолжить»
- После такого выбора проблемный файл сохраняется отключённым, остальные моды обновляются
- Ошибка переноса называется «Обновление сборки прервано»; прежняя версия сохраняется до успешного завершения

Сохраняет исправление первого открытия AWAssistant 0.1.2 из версии 1.0.13.
