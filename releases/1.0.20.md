# AWLauncher 1.0.20

- Изменение версии сборки подбирает совместимые выпуски модов с Modrinth и CurseForge
- Проверки CurseForge выполняются параллельно с ограничением числа запросов, повторные проекты проверяются один раз
- Убрано повторное чтение всей папки модов после установки каждого мода при миграции
- Добавлен раздел «Датапаки» с обеими площадками и выбором мира для установки
- Датапаки доступны в содержимом сборки; поддерживаются добавление ZIP-файлов, отключение и обновление
- Проверяются структура архива и pack.mcmeta, архив с одной внешней папкой приводится к формату Minecraft
- Каталог явно выделяет модпаки; сохранена установка Modrinth .mrpack и CurseForge .zip
- Для шейдеров, ресурспаков и датапаков добавлена проверка обновлений
- Исправлены отсутствующие переводы раздела «Скриншоты» во всех поддерживаемых языках и формат даты

Обновление сохраняет профили, миры, настройки и локальный API-ключ CurseForge
